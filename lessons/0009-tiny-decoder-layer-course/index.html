本课只学一件事：把组件接成一层

RMSNorm、GQA、RoPE 和 gated FFN 已经学过；0009 新增的是两条 pre-norm residual 的正确数据依赖。

先把字母固定下来

下面七个字母会贯穿整课。每次看到 shape，都先把字母翻译成轴的含义。

B = 1Batch size：同时处理 1 条序列
S = 3Sequence length：每条序列有 3 个 token
H = 4Hidden size：residual stream 中每个 token 有 4 个特征
Nq = 2Query head 数量
Nkv = 1Key/Value head 数量
D = 2Head dimension：每个 head 有 2 个特征；H=Nq×D
I = 6Intermediate size：FFN 内部临时扩展宽度

02

第一条支路：Attention 的完整 shape 链

重点不是重新学习 Attention，而是看清 raw、split、head 计算和 merge 分别处在哪个阶段。

从主干 H 宽，拆成 heads，再回到 H 宽

显式 head axis 出现在 Q/K/V split、scores/weights 和 head output；raw projection、merged、attention_output 都没有独立 head axis。

把通用公式代入本课数字

阶段通用 shapeB=1,S=3,H=4,Nq=2,Nkv=1,D=2这一步做什么
attention_input[B,S,H][1,3,4]主干接口
q_raw[B,S,Nq×D][1,3,4]q_proj 的扁平输出
k_raw / v_raw[B,S,Nkv×D][1,3,2]k_proj/v_proj 的扁平输出
Q split[B,Nq,S,D][1,2,3,2]建立 query head axis
K/V split[B,Nkv,S,D][1,1,3,2]保留较少 KV heads
scores / weights[B,Nq,S,S][1,2,3,3]每个 query head 的位置关系
head output[B,Nq,S,D][1,2,3,2]每个 query head 的结果
merged[B,S,Nq×D][1,3,4]head 特征重新拼接
attention_output[B,S,H][1,3,4]o_proj 后可与 x₀ 相加
QK
RoPE 中间量属于 activation

position_ids 是运行输入；由它生成的 angles、cos、sin，以及旋转后的 Q/K，都是本次 forward 的 activation，不是 Parameter，也不是跨调用 state。

为什么最终必须回到 H

residual_0 的 shape 是 [B,S,H]。逐元素相加要求 Attention 支路出口完全同形，因此 merge 后还要经过 o_proj，得到 attention_output [B,S,H]。

真实代码
residual_0 = hidden_states
attention_input = input_norm(residual_0)
attention_trace = attention.trace(attention_input, position_ids)
attention_output = attention_trace["output"]
hidden_after_attention = residual_0 + attention_output
shape 检查

x₀ 是 [B,S,H]。

norm 不改变 shape。

Attention 内部拆 head。

merge + o_proj 恢复 [B,S,H]。

同形后才能得到 x₁。

I 只是 FFN 的内部工作宽度。支路出口必须由 down_proj 压回 H，才能与 residual_1 [B,S,H] 相加。

第二次 residual 的基线是 x₁

真实代码

ffn_input = post_attention_norm(residual_1)
ffn_trace = mlp.trace(ffn_input)
ffn_output = ffn_trace["output"]

数据依赖

保存 x₁，它已经包含 x₀ 与 Attention 更新。

第二套 RMSNorm 读取 x₁。

FFN 在每个 token 内部独立计算。

down_proj 给出 H 宽修正量。

把修正量加回 x₁，得到 x₂。

≠
不能写成 x₀ + ffn_output

x₀ 不包含第一条支路的结果；第二次相加跳回 x₀，会切断 layer 的串行主干。

用一个 token 检查数据，而不是背小数

x₁[2.0018, 0.0046, 1.0073, 3.0101]x₀ + Attention branch

04

因果性、对象生命周期与执行阶段

最后把“谁能影响谁”和“哪些数据保存多久”分清；这两件事不能只靠 shape 判断。

只有 Attention 会跨 token 读取

矩阵的行是 query 位置，列是允许读取的 key/value 位置。绿色表示可以读取，灰色表示被 causal mask 屏蔽。

组件是否主动跨 token原因
RMSNorm否每个 token 只在自己的 H axis 上求均方
Attention是一个 query 会读取 causal mask 允许的历史 K/V
FFN否对每个 token 独立执行 H→I→H
Residual add否相同 token、相同 feature 逐元素相加

只修改最后一个 token，位置 0～倒数第二个位置的最终输出必须不变；只修改 token 0，后面的 token 可能通过 Attention 受到影响。

Parameter、运行输入、activation、state

类别本层对象保存多久
Parameter两个 RMSNorm weight；q/k/v/o projection weight；gate/up/down projection weight随模型 checkpoint 保存
运行输入hidden_states、position_ids每次 forward 由调用方提供
Activationnorm 输出、q/k/v raw、Q/K/V、angles、cos/sin、scores/weights、两个 residual、gate/up/mixed、x₁/x₂服务当前 forward；是否为 backward 保留由执行模式决定
请求 state0009 的 full-sequence forward 没有；0010 才加入历史 K_rope 与 V Cache跨 decode steps 保留
≠
shape 不能决定生命周期

当前 forward 中的 K/V 是 activation；相同内容在增量 decode 中被保存到 Cache 后，才成为请求 state。

full-sequence、prefill、单步 decode 的 S

阶段当前输入的 S历史 K/V Cache本课边界
full-sequence整段序列长度，例如 S=5本课不跨调用保存0009 实际执行路径
prefillprompt 长度，通常 S>1计算并建立初始 K/V Cache只复习概念，不在 0009 实现
单步 decode通常 S=1，即本步新 token读取历史 Cache，并追加本步 K/V0010 才实现
