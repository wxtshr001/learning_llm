本课只学一件事：把组件接成一层

RMSNorm、GQA、RoPE 和 gated FFN 已经学过；0009 新增的是两条 pre-norm residual 的正确数据依赖。

先把字母固定下来

下面七个字母会贯穿整课。每次看到 shape，都先把字母翻译成轴的含义。

B = 1Batch size：同时处理 1 条序列
S = 3Sequence length：每条序列有 3 个 token
H = 4Hidden size：residual stream 中每个 token 有 4 个特征
Nq = 2Query head 数量
Nkv = 1Key/Value head 数量
D = 2Head dimension：每个 head 有 2 个特征；H=Nq×D
I = 6Intermediate size：FFN 内部临时扩展宽度
