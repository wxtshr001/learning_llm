第一条支路：Attention 的完整 shape 链

重点不是重新学习 Attention，而是看清 raw、split、head 计算和 merge 分别处在哪个阶段。

从主干 H 宽，拆成 heads，再回到 H 宽

显式 head axis 出现在 Q/K/V split、scores/weights 和 head output；raw projection、merged、attention_output 都没有独立 head axis。

把通用公式代入本课数字

阶段通用 shapeB=1,S=3,H=4,Nq=2,Nkv=1,D=2这一步做什么
attention_input[B,S,H][1,3,4]主干接口
q_raw[B,S,Nq×D][1,3,4]q_proj 的扁平输出
k_raw / v_raw[B,S,Nkv×D][1,3,2]k_proj/v_proj 的扁平输出
Q split[B,Nq,S,D][1,2,3,2]建立 query head axis
K/V split[B,Nkv,S,D][1,1,3,2]保留较少 KV heads
scores / weights[B,Nq,S,S][1,2,3,3]每个 query head 的位置关系
head output[B,Nq,S,D][1,2,3,2]每个 query head 的结果
merged[B,S,Nq×D][1,3,4]head 特征重新拼接
attention_output[B,S,H][1,3,4]o_proj 后可与 x₀ 相加
QK
RoPE 中间量属于 activation

position_ids 是运行输入；由它生成的 angles、cos、sin，以及旋转后的 Q/K，都是本次 forward 的 activation，不是 Parameter，也不是跨调用 state。

为什么最终必须回到 H

residual_0 的 shape 是 [B,S,H]。逐元素相加要求 Attention 支路出口完全同形，因此 merge 后还要经过 o_proj，得到 attention_output [B,S,H]。

真实代码
residual_0 = hidden_states
attention_input = input_norm(residual_0)
attention_trace = attention.trace(attention_input, position_ids)
attention_output = attention_trace["output"]
hidden_after_attention = residual_0 + attention_output
