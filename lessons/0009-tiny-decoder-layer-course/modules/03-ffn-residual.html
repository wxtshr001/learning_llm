这一部分只需要看清两个问题：FFN 内部何时扩到 I，以及第二次 residual 为什么必须保存 x₁。

I 只是 FFN 的内部工作宽度。支路出口必须由 down_proj 压回 H，才能与 residual_1 [B,S,H] 相加。

第二次 residual 的基线是 x₁

真实代码
residual_1 = hidden_after_attention
ffn_input = post_attention_norm(residual_1)
ffn_trace = mlp.trace(ffn_input)
ffn_output = ffn_trace["output"]
layer_output = residual_1 + ffn_output
数据依赖

保存 x₁，它已经包含 x₀ 与 Attention 更新。

第二套 RMSNorm 读取 x₁。

FFN 在每个 token 内部独立计算。

down_proj 给出 H 宽修正量。

把修正量加回 x₁，得到 x₂。

≠
不能写成 x₀ + ffn_output

x₀ 不包含第一条支路的结果；第二次相加跳回 x₀，会切断 layer 的串行主干。

用一个 token 检查数据，而不是背小数
