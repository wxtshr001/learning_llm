因果性、对象生命周期与执行阶段

最后把“谁能影响谁”和“哪些数据保存多久”分清；这两件事不能只靠 shape 判断。

只有 Attention 会跨 token 读取

矩阵的行是 query 位置，列是允许读取的 key/value 位置。绿色表示可以读取，灰色表示被 causal mask 屏蔽。

组件是否主动跨 token原因
RMSNorm否每个 token 只在自己的 H axis 上求均方
Attention是一个 query 会读取 causal mask 允许的历史 K/V
FFN否对每个 token 独立执行 H→I→H
Residual add否相同 token、相同 feature 逐元素相加

只修改最后一个 token，位置 0～倒数第二个位置的最终输出必须不变；只修改 token 0，后面的 token 可能通过 Attention 受到影响。

Parameter、运行输入、activation、state

类别本层对象保存多久

运行输入hidden_states、position_ids每次 forward 由调用方提供
Activationnorm 输出、q/k/v raw、Q/K/V、angles、cos/sin、scores/weights、两个 residual、gate/up/mixed、x₁/x₂服务当前 forward；是否为 backward 保留由执行模式决定

full-sequence、prefill、单步 decode 的 S

阶段当前输入的 S历史 K/V Cache本课边界
full-sequence整段序列长度，例如 S=5本课不跨调用保存0009 实际执行路径
prefillprompt 长度，通常 S>1计算并建立初始 K/V Cache只复习概念，不在 0009 实现
单步 decode通常 S=1，即本步新 token读取历史 Cache，并追加本步 K/V0010 才实现
