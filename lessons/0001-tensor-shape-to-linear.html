2. Linear 到底做了什么

X: [M, K]
W: [K, N]
b: [N]

Y = X @ W + b
Y: [M, N]

M 可以是 token 数，K 是输入特征数，N 是输出特征数。矩阵乘法在 K 上求和，因此 K 从输出 shape 中消失。

Y[i,j] = Σₖ X[i,k] × W[k,j] + b[j]

固定 i 与 j 后，取 X 的第 i 行与 W 的第 j 列做 dot product，再加第 j 个 bias。注意是 b[j]：bias 对应输出特征，而不是输入行/token。

在 LLM 中

hidden_states: [seq, hidden]
Wq:            [hidden, q_dim]
Q:             [seq, q_dim]

Linear 独立处理每个 token 的 hidden vector，改变特征维，但不会在 token 之间交换信息。token 之间的信息混合发生在后面的 Attention。

3. 先闭卷预测，再点击检查

X:[5,128]，W:[128,64]，b:[64]

常见错误：写成 W[j,k] 是把 W 当作已经转置；写成 b[i] 是把 bias 错绑到 token。后续 Q/K/V、FFN、LM Head 都会重复使用这一索引模式。
