0006R：把 Attention 的两个求和轴接回 Decoder Block

这是一节约 25 分钟的针对性复测。已经通过的 weights 手算、shape 主链、causal 行为和 scale 不再重讲。

1. 一张数字表看清两个求和

固定 b=0、q=1，设 D=2，Q 为 [1,2]，两个 K 为 [1,0]、[0,1]：

score[0,1,0] = (1*1 + 2*0) / sqrt(2)
score[0,1,1] = (1*0 + 2*1) / sqrt(2)

score[b,q,k] = sum over d (Q[b,q,d] * K[b,k,d]) / sqrt(D)

第一次求和消掉 feature 轴 d，留下 [b,q,k]。softmax 后假设这一行 weights 是 [0.25,0.75]，V 为 [[2,4],[6,8]]：

output[0,1,0] = 0.25*2 + 0.75*6 = 5
output[0,1,1] = 0.25*4 + 0.75*8 = 7

output[b,q,d] = sum over k (weights[b,q,k] * V[b,k,d])

第二次求和消掉 key position 轴 k，留下 [b,q,d]。记忆句：score 沿 d 比较特征，output 沿 k 汇集位置。

2. Attention 子层不能从 projection 直接跳到 residual

hidden_states [B,S,H]
  ├────────────────────────────── residual ──────────────────────┐
  └→ RMSNorm → Q/K/V projections → causal attention             │
       → merge heads（单头时是退化情况）→ output projection ────┤
                                                                ↓
                                                          add → h

h ────────────────────────────── residual ───────────────────────┐
└→ RMSNorm → gated FFN ──────────────────────────────────────────┤
                                                               ↓
                                                     add → layer_output

Q/K/V projection 只产生 Attention 的输入；causal attention 才跨 token 汇集 V；output projection 把 head 结果重新组合为 H 维改变量；然后才能与原 hidden_states 做第一次 residual add。

多个 decoder layers 之后还要经过 final RMSNorm 和 LM Head，才从 [B,S,H] 变成 [B,S,VocabSize] logits。因此本课 attention output 不是 next-token logits。

3. 两个代码 contract

# D 必须严格大于 0
if head_dim <= 0:
    raise ValueError(...)

# mask 必须跟输入在同一个 device
mask = make_causal_mask(sequence_length, query.device)

head_dim < 0 没有作用，因为 tensor shape 不可能为负；真正需要拒绝的是 D=0。把 mask 固定建在 CPU 会在 CUDA query 上发生 device mismatch。
