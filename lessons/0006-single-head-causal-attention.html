0006：一个 token 怎样只读取自己和过去

本课实现 single-head causal attention（单头因果注意力）。single-head 表示暂时只有一组 Q、K、V；causal 表示位置 q 只能读取 key 位置 k <= q，不能看到未来。多头和 GQA 留到第 0007 课。

1. 进入条件、符号和成果

可以依赖：你已通过 `[B,S,H]`、transpose、Linear、dtype/device、Module、RMSNorm/FFN 与参数/运行 tensor shape 门禁。
必须从零解释：Q/K/V 在 attention 中的角色、score、scale、causal mask、softmax axis 与 value 加权。
符号含义
BBatch size，同时处理的序列数。
SSequence length，每条序列的 token 数。
D单个 attention head 的特征数。
qquery position，当前正在产生输出的 token 位置。
kkey position，被当前 query 比较和读取的位置。

Q、K、V 均为 rank 3 tensor，shape [B,S,D]。本课成果是得到 weights [B,S_query,S_key] 和 output [B,S,D]，并证明未来 token 不影响过去输出。

2. 先用 D=1 得到可手算的精确结果

令 B=1、S=3、D=1：

Q = [[1], [1], [1]]
K = [[1], [1], [1]]
V = [[1], [3], [5]]

每个 query 与每个 key 的点积都是 1；D=1，所以除以 sqrt(D)=1 后 score 仍是 1。causal mask 只保留当前位置及过去：

允许矩阵 [q,k]:
q0: [允许, 禁止, 禁止]
q1: [允许, 允许, 禁止]
q2: [允许, 允许, 允许]

mask 后 scores:
q0: [1, -inf, -inf]
q1: [1,    1, -inf]
q2: [1,    1,    1]

softmax 沿 key 轴计算。相等 score 会得到均匀权重：

weights q0 = [1,   0,   0]
weights q1 = [1/2, 1/2, 0]
weights q2 = [1/3, 1/3, 1/3]

output q0 = 1*1                         = 1
output q1 = 1/2*1 + 1/2*3              = 2
output q2 = 1/3*1 + 1/3*3 + 1/3*5      = 3
score 决定“读多少”，V 提供“读到的内容”。最终 output 是同一 query 行的 attention weights 对所有允许 V 的加权和。

3. 推广到 D 个特征和完整 shape

Q:                    [B,S,D]
K:                    [B,S,D]
K.transpose(-2,-1):  [B,D,S]
Q @ K^T:             [B,S_query,S_key]

逐元素 score 公式：

score[b,q,k] = sum over d of Q[b,q,d] * K[b,k,d] / sqrt(D)

矩阵乘法只对 D 轴求和，留下 query 和 key 两个 S 轴。mask shape 是 [S,S]，广播到所有 B。softmax 使用 dim=-1，即每个 query 固定后沿 key 轴归一化。

weights = softmax(masked_scores, dim=-1)  # [B,S_query,S_key]
output  = weights @ V                    # [B,S,D]

output 的逐元素关系：

output[b,q,d] = sum over k of weights[b,q,k] * V[b,k,d]

4. causal mask 为什么必须在 softmax 前

禁止未来 key 的标准做法是把对应 score 设成负无穷，再做 softmax。因为 exp(-inf)=0，未来位置权重严格为 0，允许位置重新归一化后每行和为 1。

如果先 softmax 再把未来权重设为 0，剩余权重行和会小于 1；除非额外重新归一化，否则已不是同一个 attention 分布。

修改 V 的未来位置 2 时，query 0、1 都被 mask 阻止读取它，所以这两个输出必须保持不变；query 2 可以读取位置 2，因此可能改变。这是比“shape 正确”更强的因果性测试。

5. 为什么除以 sqrt(D)

点积是 D 项乘积之和。D 增大时，score 的典型幅度也容易增大，使 softmax 过度尖锐。除以 sqrt(D) 把 score 尺度控制在更稳定的范围。scale 不改变 shape，只改变 softmax 前的数值。

代码必须从 Q 的最后一维读取 D，不能把 D 写成 S 或模型 hidden size。

6. PyTorch 实现与调试顺序

D = query.shape[-1]
scores = query @ key.transpose(-2, -1) / sqrt(D)
future_mask = triu(ones(S,S,bool), diagonal=1)
masked_scores = scores.masked_fill(future_mask, -inf)
weights = softmax(masked_scores, dim=-1)
output = weights @ value

依次检查：Q/K/V shape 相等；scores 为 `[B,S,S]`；mask 对角线和下方允许；weights 每行和为 1；未来权重为 0；output 为 `[B,S,D]`。
