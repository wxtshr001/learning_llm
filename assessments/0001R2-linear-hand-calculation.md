# 0001R2：Linear 手算复测

请闭卷、纸笔完成。每个输出元素先写 dot product，再加 bias；不要只写最终矩阵。

## 1. 向量输出

```text
X = [[2, 3]]
W = [[4],
     [5]]
b = [6]
```

计算 `Y = X @ W + b`。

## 2. 两行、两输出

```text
X = [[1, 2],
     [4, 3]]

W = [[2, 0],
     [1, 3]]

b = [5, 7]
```

分别展开并计算 `Y[0,0]`、`Y[0,1]`、`Y[1,0]`、`Y[1,1]`，最后写出完整矩阵。

## 3. 无 bias 对照

```text
X = [[-1, 2, 1]]
W = [[2, 1],
     [3, 0],
     [4, -2]]
b = [0, 0]
```

展开并计算完整输出。

## 通过标准

三题全部正确。若只是单次加减笔误，会换一个元素即时复核；若 dot product 配对错误，则继续针对性练习。
