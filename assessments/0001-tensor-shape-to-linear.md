## 题目

### 1. 输出 shape（关键题）

```text
X: [3, 4]
W: [4, 2]
b: [2]
Y = X @ W + b
```

`Y` 的 shape 是什么？为什么？

```text
[3,2]，x的行+w的列，b是偏置广播，与w列维度保持一致
```

### 2. 元素公式（关键题）

请写出 `Y[1,0]` 的完整公式。必须明确求和索引以及 bias 使用哪个下标。

```text
Y[1,0] = X[1,:]*W[:,0]+b[0]
```

### 3. 手算

```text
X = [[1, 2],
     [3, 4]]

W = [[1, 0],
     [0, 2]]

b = [10, 20]
```

计算 `X @ W + b`。

```text
[[11, 23],
 [14, 38]]
```

### 4. 广播

为什么 `b=[2]` 可以加到 `[3,2]`，但通常不能直接加到 `[3,4]`？

```text
因为2和4对不齐
```

### 5. 维度语义

当 `X=[seq=3, hidden=4]`、`W=[hidden=4, out=2]` 时：

- 哪个维度表示 token 数？
- 哪个维度被线性层改变？
- 为什么 token 数没有改变？

```text
x seq 3表示token数
hidden=4是线性层
因为与w相乘改变的是hidden维度
```

### 6. Debug

有人把元素公式写成：

```text
Y[i,j] = sum(X[i,k] * W[j,k]) + b[i]
```

指出其中两个索引错误，并给出正确版本。

```text
Y[i,j] = sum(X[i,k] * W[k,j]) + b[j]
```

### 7. 迁移到 LLM（关键题）

```text
hidden_states: [seq=5, hidden=128]
Wq: [128, 64]
```

- `Q = hidden_states @ Wq` 的 shape 是什么？
- `Wq` 从模型角度表示什么？
- 这一步是否在不同 token 之间混合信息？为什么？

```text
[5, 64]
根据输入的x embedding解算出Q value的模型参数
不是，只是单独一个Q value，还没有与其他K V相乘混合信息
```
