# 0008 闭卷测试：RoPE 从二维旋转到 GQA

完成引导与独立代码后，关闭课程、代码和速查表作答。

## 提交证据

粘贴两个脚本的完整运行输出。

## 1. Qwen half-split 逐元素旋转（关键题，25 分）

给定一个 head vector `x=[2,3,5,7]`，Qwen-style half-split layout，且某位置的：

```text
cos=[0,1,0,1]
sin=[1,0,1,0]
```

1. 写出 `D`、两个配对轴以及 `rotate_half(x)`；
2. 逐元素计算 `x_rope=x*cos+rotate_half(x)*sin`；
3. 说明为什么 D 必须为正偶数、RoPE 是否改变 shape；
4. 分别计算旋转前后向量长度，说明结果。

## 2. 相对位置与 score（关键题，25 分）

在一个二维简化例子中，每增加一个 position 就逆时针旋转 90°，原始 `q=k=[1,0]`：

1. 写出 position 0、1、2 的旋转后向量；
2. 计算 `score(0,1)`、`score(1,2)`、`score(0,2)`；
3. 为什么前两个 score 相同？这说明 RoPE 怎样把相对位置写入 Q/K 点积？
4. RoPE 能否替代 causal mask？为什么？

## 3. GQA shape、广播与执行位置（关键题，30 分）

给定 `B=2,S=7,Nq=8,Nkv=2,D=6`：

1. 写出 `position_ids`、`inv_freq`、angles、复制后的 embedding、cos/sin 的 shape；
2. 写出 Q/K/V、unsqueeze 后 cos/sin、Q_rope/K_rope 的 shape，并标出每个 axis 的含义；
3. 为什么同一个 `[B,1,S,D]` cos/sin 能同时广播到 Nq=8 的 Q 和 Nkv=2 的 K？
4. 从 q/k/v projection 开始，写出 split、RoPE、Cache、GQA attention、merge、`o_proj` 的顺序；明确哪些对象被旋转、V 是否旋转、Cache 中的 K 是旋转前还是旋转后；
5. 单步 decode 已有 7 个历史 token 时，新 token 的 `position_id` 应是多少？为什么不能重置为 0？

## 4. 实现与系统边界（20 分）

1. 用自己的话解释 `x*cos + rotate_half(x)*sin` 如何对应二维旋转；
2. 默认 RoPE 中哪些是 Parameter、Activation、buffer/config 和请求 State？
3. 写出至少三个实现不变量，可用于 eager/export/runtime 数值对齐；
4. 为什么 Q/K head 数不同不要求在 RoPE 前 repeat K？
