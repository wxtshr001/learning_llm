常见 dtype

dtype字节/元素典型用途
float324参考浮点计算
float162降低推理存储与带宽
bfloat162另一种 16 位浮点格式
int648整数索引、常见 token id
数据字节数 = x.numel() * x.element_size()

创建与转换

x = torch.tensor(data, dtype=torch.float32, device="cpu")
target = torch.device("cuda:0" if torch.cuda.is_available() else "cpu")
y = x.to(device=target, dtype=torch.float16)
back = y.to(device="cpu", dtype=torch.float32)

.to() 需要转换时通常复制；已经满足要求时可以返回原 Tensor。

计算前检查

  • 参与同一普通运算的 Tensor 是否在兼容 device？
  • dtype 是否是目标 kernel 支持的类型？
  • 跨设备拷贝是否放在循环或逐算子热路径中？
  • 比较结果时是否先统一 device 与 dtype？
