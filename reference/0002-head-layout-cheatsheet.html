Head Layout 详细速查表

先把字母翻译成含义，再代入数字。不要只背 shape。

五个符号

符号英文含义例子
BBatch同时处理的序列数2
SSequence length每条序列的 token 数5
HHidden size每个 token 的总特征数128
NNumber of headshead 数量4
DHead dimension每个 head 的特征数32

H=N×D；例：128=4×32。

标准变换

输入: [B,S,H]
      每条序列 × token × token总特征

reshape(H -> N×D)
   -> [B,S,N,D]

transpose(1,2): 交换 S 与 N
   -> [B,N,S,D]

元素映射:
heads[b,n,s,d] = x[b,s,n*D+d]

dim 编号

layoutdim 0dim 1dim 2dim 3
[B,S,N,D]BSND
[B,N,S,D]BNSD

transpose(1,2) 只交换 dim 1 和 dim 2。

存储边界

API简化心智模型
view只改 shape 解释；stride 不兼容就失败。
reshape给出目标 shape；可能共享 storage，也可能复制。
transpose交换轴，通常共享 storage，常得到 non-contiguous view。
contiguous按当前逻辑顺序整理为连续 storage。
