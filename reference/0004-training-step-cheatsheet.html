Module / Autograd / Optimizer 速查

对象职责

对象/调用职责不负责
nn.Module组织计算、注册 Parameter/子 Module不会自动训练
nn.Parameter被 Module 注册的可训练 Tensor不会自行更新
model(x)经 Module 调用机制执行 forward不修改参数
loss.backward()计算并累积梯度到 .grad不修改参数
optimizer.step()根据现有 grad 修改参数不替代 backward
optimizer.zero_grad()清除上一轮累积梯度不清参数值

标准单步

optimizer.zero_grad()
prediction = model(x)
loss = loss_fn(prediction, target)
loss.backward()
optimizer.step()

SGD

new_parameter = old_parameter - learning_rate * gradient

正学习率下，负梯度使参数增大，正梯度使参数减小。

有限差分

gradient ≈ [L(parameter + epsilon) - L(parameter - epsilon)] / (2 * epsilon)

扰动时关闭 grad 并恢复参数；它用于验证，不用于正式训练。

推理

model.eval()
with torch.inference_mode():
    output = model(x)
eval() 改 Module 训练/评估行为；inference_mode() 关闭 autograd 记录。两者不是同一件事。
