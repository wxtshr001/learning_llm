RMSNorm

variance = x.float().pow(2).mean(-1, keepdim=True)  # [B,S,1]
y = x * rsqrt(variance + eps)                       # [B,S,H]
out = y * weight                                    # weight [H]

沿最后 H 轴；不减均值；shape 不变。

Gated FFN

gate = silu(gate_proj(x))  # [B,S,I]
up = up_proj(x)            # [B,S,I]
mixed = gate * up          # [B,S,I]
out = down_proj(mixed)     # [B,S,H]
weightshape
gate_proj.weight[I,H]
up_proj.weight[I,H]
down_proj.weight[H,I]
