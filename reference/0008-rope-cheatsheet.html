RoPE 速查：Qwen Half-split Layout

系统位置

q/k/v projections → split [B,N,S,D]
→ RoPE(Q,K only) → Cache rotated K + original V
→ GQA attention → merge → o_proj

half-split rotation

x = [x0,x1,x2,x3]
rotate_half(x) = [-x2,-x3,x0,x1]
x_rope = x*cos + rotate_half(x)*sin

D 必须为正偶数；配对为 (0,D/2)、(1,D/2+1)...。

cos/sin

position_ids: [B,S]
inv_freq: [D/2]
angles = position_ids[...,None] * inv_freq  # [B,S,D/2]
embedding = cat(angles,angles)               # [B,S,D]
cos/sin = embedding.cos()/sin()

GQA broadcast

cos/sin [B,S,D] → unsqueeze(1) → [B,1,S,D]
Q [B,Nq,S,D]   → Q_rope same shape
K [B,Nkv,S,D]  → K_rope same shape
V [B,Nkv,S,D]  → unchanged

不变量

  • position 0：cos=1、sin=0，输出等于输入。
  • 旋转保持每个 head vector 的长度。
  • 相同相对位置差产生相同的位置旋转差。
  • RoPE 不替代 causal mask。
