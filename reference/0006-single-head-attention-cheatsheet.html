单头 Causal Attention 速查

在 decoder layer 中的位置

hidden_states
 → RMSNorm → Q/K/V projections
 → causal attention（本课）→ merge/o_proj → + residual
 → RMSNorm → gated FFN → + residual
 → next decoder layer

全部 layers → final norm → LM Head → next-token logits

Q/K/V 分工

Qquery：当前位置按什么特征寻找
Kkey：每个位置按什么特征被匹配
Vvalue：匹配后真正被加权读取的内容

Q/K 决定读多少；V 决定读到什么。

完整内核

Q,K,V: [B,S,D]
K^T:   [B,D,S]
scores = Q @ K^T / sqrt(D)       # [B,S_query,S_key]
scores = scores.masked_fill(future_mask, -inf)
weights = softmax(scores, dim=-1) # 沿 key 轴，每行和 1
output = weights @ V              # [B,S_query,D]

score[b,q,k]=sum_d Q[b,q,d]*K[b,k,d]/sqrt(D)

output[b,q,d]=sum_k weights[b,q,k]*V[b,k,d]

因果与执行形态

causal 条件：仅允许 k<=q。未来权重为 0，修改未来 V 不得改变过去 query 的输出。

full sequence / prefill多个 query，score 常为方形；mask 防未来
decode通常一个新 query 读取历史 K/V Cache；softmax 仍沿 key axis

KV Cache 保存历史 K/V，不保存 weights，也不是 Parameter。

四问定位法

  1. 输入从哪里来？
  2. 沿哪个 axis 读写哪些位置？
  3. 输出交给谁，怎样回 residual stream？
  4. full-sequence、prefill、decode 时 shape/状态怎样变化？
