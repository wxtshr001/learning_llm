Tiny Decoder Layer 速查

两条 pre-norm residual

x0 = hidden_states
a  = input_norm(x0)
b  = self_attn(a, position_ids)
x1 = x0 + b

c  = post_attention_norm(x1)
d  = mlp(c)
x2 = x1 + d

第二次 residual 的基线是 x1，不是原始 x0。

完整 shape 主线

x0 / norm / attention_output / x1: [B,S,H]
Q: [B,Nq,S,D]   K/V: [B,Nkv,S,D]
weights: [B,Nq,S,S]
gate / up / mixed: [B,S,I]
ffn_output / x2: [B,S,H]

谁混合 token

组件跨 token？说明
RMSNorm否只在每个 token 的 H axis 求均方
Attention是每个 query 汇集允许看到的 key/value positions
Gated FFN否每个 token 独立做 H→I→H
Residual add否相同 token、相同 feature 逐元素相加

对象分类

  • Parameter：两个 norm weight；q/k/v/o projection weight；gate/up/down projection weight。
  • 运行输入：hidden_states、position_ids。
  • Activation：norm 输出、Q/K/V、cos/sin、weights、branch 输出、x1/x2。
  • 0009 请求 state：无。0010 加入的历史 K_rope/V Cache 才是跨 decode step state。

三个关键不变量

  1. layer 输入输出都是 [B,S,H]。
  2. 把 attention 的 o_proj 和 FFN 的 down_proj 置零，整个 layer 应成为 identity。
  3. 改变未来 token 不得影响更早位置输出。
