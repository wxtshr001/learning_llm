MHA / GQA / MQA 速查

三个结构

MHANkv=Nq，每个 Q head 独占 K/V head
GQA1<Nkv<Nq，每组 Q heads 共享 K/V
MQANkv=1，所有 Q heads 共享 K/V
Nq % Nkv == 0
group_size = Nq // Nkv
kv_head = q_head // group_size

Nq=4,Nkv=2: [0,0,1,1]

shape

hidden: [B,S,H]
q raw:  [B,S,Nq*D]  → Q [B,Nq,S,D]
k/v raw:[B,S,Nkv*D] → K/V [B,Nkv,S,D]  # Cache 保存
logical K/V for compute: [B,Nq,S,D]
weights/head output: [B,Nq,S,S] / [B,Nq,S,D]
merge: [B,S,Nq*D]
o_proj: [B,S,H]

projection

q_proj: Linear(H,Nq*D), weight [Nq*D,H]
k_proj: Linear(H,Nkv*D), weight [Nkv*D,H]
v_proj: Linear(H,Nkv*D), weight [Nkv*D,H]
o_proj: Linear(Nq*D,H), weight [H,Nq*D]

GQA 只减少 k/v projection；q/o 不因 Nkv 减少。

KV Cache

bytes = 2 * B * L * Nkv * S_cache * D * bytes_per_element
        ↑ K+V

GQA/MHA cache ratio = Nkv/Nq

Cache 保存 repeat 前的 Nkv heads。Q 不缓存。repeat 是计算映射，不应把 expanded Nq K/V 存入 Cache。

系统路径

hidden → RMSNorm → q/k/v projections → split
→ RoPE(Q,K) → update/read KV Cache
→ GQA causal attention → merge → o_proj → residual

Prefill 仍有 Nq 份 score；decode 读取历史 K/V，减少 Nkv 可降低 Cache 容量与带宽压力。端到端速度必须实测。
